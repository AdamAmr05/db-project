# Plan: AI SDK + json-render streaming charts in chat

## Goals
- Migrate the existing Express `/api/chat` Gemini integration to Vercel AI SDK 6 with streaming text.
- Keep the current `runCode` JS execution model + SELECT-only guardrails.
- Add json-render UI blocks (charts) that can appear inline with text responses.
- Use json-render’s JSON Patch stream format for progressive UI updates.
- Keep charts consistent with the existing design language, enhanced with shadcn/ui styling.

## Scope Overview
- Backend: move to AI SDK v6 streaming and expose UI patch stream alongside text.
- Frontend: replace request/response chat with streaming + inline UI parts rendered via json-render.
- UI: introduce chart components (Recharts) wrapped in shadcn/ui styling.

## Implementation Steps
1. **Backend dependencies + model setup**
   - Add AI SDK v6 deps (`ai`, `@ai-sdk/google`) to root `package.json`.
   - Update `/api/chat.js` to use `streamText` + `createDataStreamResponse` for SSE streaming.
   - Keep `isSelectOnly`, `createQueryFunction`, `runCode`, and `describeTable` intact.

2. **Tooling + streaming protocol**
   - Convert Gemini tool definitions into AI SDK tool schema (e.g., `runCode`, `describeTable`).
   - Add a `renderChart` tool that returns chart specs and emits json-render patch ops through `StreamData`.
   - Stream text chunks via AI SDK text stream into the same SSE response.
   - Update `api/schema-context.js` to explain when to emit chart UI patches, and to keep verbose textual explanations.

3. **Frontend streaming client**
   - Replace `frontend/src/services/chatService.js` with a streaming client that reads SSE chunks and dispatches:
     - Text deltas → append to the active assistant message.
     - UI patch ops → feed into json-render `useUIStream` state.
   - Update `frontend/src/components/ChatWidget.jsx` to manage messages as “parts” (text + ui blocks), keeping inline order.
   - Maintain existing markdown/table formatting for text parts.

4. **json-render catalog + registry**
   - Add a catalog/registry under `frontend/src/json-render/` defining chart components and allowed props.
   - Use JSON Patch format compatible with `useUIStream` / `Renderer` (e.g., `[{ op: "set", path: "/root", value: ... }]`).
   - Create chart block renderer(s) using Recharts with shadcn/ui Card styling.

5. **Shadcn/ui setup**
   - Add shadcn/ui dependencies (radix + class-variance + tailwind-merge as needed) in `frontend/package.json`.
   - Add `components/ui/card` (or equivalents) with Tailwind styling to match the app theme.
   - Use these wrappers in chart blocks for consistent design.

6. **Polish + safeguards**
   - Ensure streaming order preserves text/chart interleaving.
   - Enforce chart data limits and graceful fallback when datasets are large or empty.
   - Add prompt guidance to keep textual explanation alongside visualizations.
